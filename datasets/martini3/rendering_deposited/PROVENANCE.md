The protein model was generated by the authors with martinize2/vermouth
0.10.0, Martini 3001, elastic network and sidechain corrections. Its original
command, secondary structure and force-field citations remain in the ITP.
The phosphatidylinositol model cites Borges-Araujo et al.,
*Improved Parameterization of Phosphatidylinositide Lipid Headgroups for the
Martini 3 Coarse-Grain Force Field*, JCTC (2021),
<https://doi.org/10.1021/acs.jctc.1c00615>.

## Selected snapshots

- AA: `ALL.ATOM/REPLICA1/final-1.gro`, CHARMM36m.
- CG: `COARSE.GRAINED/final_10mus.gro`, Martini 3; its title records
  `t=10000000.00000` ps, i.e. 10 microseconds.
- Inventories come from the corresponding deposited TOP files and match
  every retained atom name and residue name.
- Both systems have six protein chains and 1,246 residues.
- AA membrane: 612 POPC, 432 POPE, 156 POPI (1,200 lipids).
- CG membrane: 1,442 POPC, 1,037 POPE, 375 POPI (2,854 lipids).
- Retained block totals: 177,191 AA atoms and 38,255 CG sites.

These are independent trajectories of corresponding systems, **not**
identical-size membranes or a one-to-one mapping between final snapshots.
Neither contains nucleic acids. Using them without RNA and with different
lipid counts was explicitly approved; isolated DNA/tRNA examples remain
elsewhere in the main scenes.

## Changes made for the rendering fixture

1. Remove water, sodium/chloride ions and velocities, retaining all protein
   atoms/sites and all lipids. No membrane crop or molecule insertion.
2. Reconstruct periodic whole molecules using the published bonds,
   constraints and virtual-site connectivity. Translate each whole molecule
   to the periodic image nearest the source box center. No relaxation,
   tail straightening, random rotations or coordinate remapping.
3. Fit the AA protein to the CG protein using corresponding CA/BB positions
   for all 1,246 residues. Apply that single proper rotation and translation
   to the complete AA assembly, including its membrane. Fit RMSD:
   0.895804 nm. No scaling; the membranes retain their different dimensions.
4. Translate both snapshots into the side panel with CG membrane center
   `(97,25,12)` nm. Original isolated examples and four ligands are unchanged.
   GRO coordinates are rounded to 0.001 nm. Input CG precision is 0.01 nm.
5. Copy the protein and selected POPC/POPE/POPI molecular ITP blocks exactly,
   except for molecule-type names `DEP_SND3`, `DEP_POPC`, `DEP_POPE`,
   `DEP_POPI`. This keeps the deposited parameters separate from the newer
   Lipidome models used by the isolated lipid examples.

The deposited `martini_v3.0.0.itp` SHA-256 is
`0ecbf0ff334b2ec21dc5e3151aca42167b977bc2aed41eb2a44bd8c997754894`,
identical to `../martini_v3.0.0.itp`. The AA molecular ITPs are retained for
coordinate/inventory checks and periodic reconstruction, not to create an
atomistic simulation topology for the combined rendering scene.

The enlarged, solvent-free rendering scene is **not a reproduction of the
original solvated periodic simulation environment**. The displayed
conformations come from simulations, but the entire rendering panel is not
equilibrated or suitable for production dynamics. The rebuilt CG TPR has
the genuine molecular connectivity and a zero-step validation integrator.
No guessed bonds, warning overrides or generic particle types are used.

## Offline reproduction and verification

From the repository root:

```sh
node datasets/martini3/rendering_deposited/build.mjs
node datasets/martini3/assemble_rendering.mjs
cd datasets/martini3
gmx grompp -f rendering_visualization.mdp -c ../rendering_martini_cg.gro \
  -p rendering_visualization.top -o ../rendering_martini_cg.tpr
cd ../..
node --test datasets/martini3/rendering_deposited/build.test.mjs \
  datasets/martini3/validate_rendering.test.mjs \
  datasets/martini3/rendering_lipids/build.test.mjs \
  datasets/martini3/rendering_ligands/build.test.mjs
```

Tests verify every imported coordinate against its source modulo periodic
images and rigid alignment, unbroken CG bonded vectors, source parameter
fidelity, final-snapshot provenance, mixed lipid inventories, leaflet
roughness and distinct lipid tail conformations. Integration tests verify
unchanged isolated AA examples/ligands, compiled TPR connectivity, exact
label/coordinate round-trip and finite zero-step energy/forces. The initial
zero-step check gave potential energy -414,890.75 kJ/mol and maximum force
162,985.17 kJ/mol/nm; these are sanity checks, not equilibration criteria.
